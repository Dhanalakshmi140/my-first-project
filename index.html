GitHub Essentials: Repos and Pull Requests

Learn how to create repositories and submit pull requests.

What is a Repository?

A repository (repo) is a storage space for your project. It contains project files and complete history of changes.

Key Components

  • README.md
  • Branches
  • Commits
  • Issues
  • .gitignore

Pull Request Workflow

  1. Create a branch
  2. Make commits
  3. Push to GitHub
  4. Open Pull Request
  5. Review & Merge
